Tagsplit

Tagsplit helps several households run one yard sale together: price tags, checkout at the table, and a fair payout at the end.

Start a sale and add the households taking part. Each one gets a color and a two-letter code. Add items with a photo, a price and the household it belongs to. Every item gets a number like OR-07.

Tags print on Avery 5160, Avery 5163 or A4 3 × 8 label sheets. Use Start at label to skip labels already used on a sheet. New & changed prints only items you added or repriced since the last time you shared the PDF.

At checkout, tap items to add them. Tap a line to change the price the buyer paid. For things without a tag, type the household code and the amount, like PK 3.

Settle up shows each household's payout: what it sold, minus its share of shared costs, plus anything it paid for out of pocket. Costs can be split by sales or evenly, and the shares always add up to the cent.

If an item can't be deleted, it has already been sold. Sold items stay on the books so the payouts add up. Lower the quantity instead, or undo the order from Settle up.
