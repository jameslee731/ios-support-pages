Ownhand

Ownhand turns letters you write with a finger into a font you can type with inside the app.

Tap Try the sample font on an empty home screen. It is a finished hand, so you can read the sample, write a card, and share the font file without writing first.

To make your own, tap New font, pick Fine, Medium, or Bold, and write each letter in the box. Lift your finger and that stroke is saved. Next moves to the following letter. Undo stroke removes the last stroke.

Tune changes weight, letter spacing, and kerning. Write a card sets your message on Plain, Lined, Kraft, or Tag paper. Export image and Export PDF share that card. Export font shares the .ttf once all 26 lowercase letters or all 26 capitals are written.

The font file can go to a computer, or to an app that imports fonts. iPhone does not let apps add new system fonts, so the letters are used inside Ownhand and in the file you share.

Fonts stay on this iPhone until you delete them. Delete all fonts is in About.
